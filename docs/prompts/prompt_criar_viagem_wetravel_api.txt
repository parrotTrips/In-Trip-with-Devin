10. Regras de seguranca

- Nunca commitar tokens, API keys, cookies ou credenciais.
- Se precisar rodar chamadas reais contra producao, pedir confirmacao antes.
- Preferir dry-run/sandbox quando disponivel.
- Nao sobrescrever viagens existentes.
- Antes de criar, procurar se ja existe uma viagem com title "Parrot Rio Full App Simulation" ou slug "parrot-rio-full-app-simulation".
- Se existir, nao criar duplicata sem confirmacao; em vez disso, listar o registro existente e perguntar se deve atualizar, arquivar ou reutilizar.
